# 🐉 GOKU'S AWESOME DBZ PAGE 🐉

A nostalgic tribute to the golden age of GeoCities and Dragon Ball Z fan sites!

## 🌟 Features

This project recreates the authentic 90s GeoCities web experience:

- **Authentic GeoCities Design**: Wild colors, Comic Sans, table-based layouts
- **Animated Elements**: Marquee text, blinking text, rainbow animations
- **Classic Retro Elements**:
  - Visitor counter with glowing LED-style digits
  - "Under Construction" banners
  - Web ring navigation
  - MIDI player reference
  - Award badges
  - "Best viewed in IE 5.0" notice
- **DBZ Character Gallery**: ASCII art character cards with modal details
- **90s Web Aesthetics**: Frames simulation, wild color gradients, heavy borders

## 🚀 Tech Stack

Built with modern tools to recreate vintage vibes:
- **Vue 3** with Composition API
- **TypeScript** for type safety
- **Vite** for fast development

## 📦 Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 GeoCities Easter Eggs

- Rainbow gradient header
- Pulsing and glowing animations
- Table-based layout (authentic 90s style!)
- Visitor counter persists in localStorage
- Character cards with hover effects
- Modal popups for character details

## 📜 About

This is a loving parody of late 90s/early 2000s GeoCities fan sites, specifically those dedicated to Dragon Ball Z. It captures the enthusiasm, wild design choices, and unrestrained creativity that defined the early web.

Remember when:
- MIDI files auto-played on page load?
- Every site had a visitor counter?
- "Under Construction" GIFs were everywhere?
- Comic Sans was the font of choice?
- Web rings connected all fan sites?

This project remembers. 🌈✨
